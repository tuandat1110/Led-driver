## Architecture
- The architecture consists of multiple layers:
  - **Hardware Layer:** This is where the physical components are connected.
  - **Firmware Layer:** The core logic that runs on the microcontroller.
  - **Application Layer:** User-interface and interaction logic, which communicates with the firmware.
